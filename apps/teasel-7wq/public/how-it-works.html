How the shared list works

Three small steps from a blank list to a shared one.

1. Add an item

Type what needs doing and it lands at the top of the list.

2. Share it

Everyone with the link sees the same list, updated as it changes.

3. Tick it off

Finished items stay visible with a check mark, so nothing quietly disappears.

Teasel keeps the list small on purpose: the five newest items, shown the same way for everyone, so the whole team can read it in a glance.
